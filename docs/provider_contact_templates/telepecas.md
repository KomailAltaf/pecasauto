# TelePeças API access request

Subject: API evaluation for Portuguese vehicle identification and parts ecommerce

We are evaluating a Portuguese automotive-parts ecommerce platform and would like sandbox/API access for a controlled benchmark of Portuguese vehicles.

Please confirm:

- endpoints for Portuguese matrícula and VIN decoding;
- returned fields: make, model, generation, year, fuel, displacement, engine family/code, kW/CV, exact variant;
- whether the result includes TelePeças model ID, TecDoc model ID and/or KType;
- OEM/reference search, aftermarket fitment and restriction data;
- commercial ecommerce/display rights;
- automated-access, caching, persistent storage and retention rights;
- sandbox limits, production limits, SLA and support;
- public, monthly, volume and reseller pricing;
- mapping rights into our internal canonical vehicle catalogue.

Initial test case after access: Portuguese plate `CG-17-GC` and its client-supplied VIN.
