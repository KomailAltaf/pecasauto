# Autofrance public API production-use questions

Subject: VIN→KType API use for a Portuguese automotive ecommerce platform

We tested the documented public endpoint with one Portuguese-market Peugeot VIN and received KType 130708 plus detailed engine data. Before any production use, please confirm:

- whether commercial server-side ecommerce use is permitted;
- supported brands and coverage outside Sweden, especially Portugal;
- whether KType and vehicle fields may be displayed, cached or persistently stored;
- API stability/versioning, SLA and sustained-volume limits;
- whether the 10/min public limit is intended only for evaluation;
- higher-volume/commercial pricing;
- source/licence of KType and TecDoc-linked product data;
- permission to map returned KTypes into another licensed catalogue;
- handling and support for conflicting VIN results.
